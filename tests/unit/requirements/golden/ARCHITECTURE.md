## Stack

**Python / FastAPI** (`python-fastapi`) with postgresql.

- src layout: src/web_shop/ with routers per resource
- pydantic models for request/response schemas
- pytest with httpx TestClient; ruff for lint and format
- schema migrations versioned with the code; no ORM auto-DDL in production

Commands:
- test: `uv run pytest`
- lint: `uv run ruff check .`
- format: `uv run ruff format .`
