# Roadmap

## Phase 0 — Foundation
Monorepo, domain models, configuration, logging, local DB, API contracts, policy/permission engine, tool registry and tests.

## Phase 1 — Developer MVP
CLI, project registry, app launcher, filesystem/shell/Git, repository analysis, AI providers/router, coding workflow, approvals, checkpoints and audit.

## Phase 2 — Voice + Desktop
Tauri UI, wake word, STT/TTS, hotkey, notifications, screen analysis and job controls.

## Phase 3 — Requirements Studio
Interview engine, full requirements pipeline, hierarchical approvals, traceability, estimates, document exports and Claude skills.

## Phase 4 — Knowledge + Integrations
Company knowledge, email read/draft, calendar, Jira/Azure DevOps approval-gated writes, selected cloud storage and web knowledge.

## Phase 5 — Distributed Panos
Control plane, node identity/presence, secure remote dispatch and React web dashboard.

## Phase 6 — Mobile
React Native companion for voice, monitoring and approvals.

## Phase 7 — Learning/Optimization
Estimate-vs-actual learning, richer model routing/cost optimization, advanced project analytics and reusable organization patterns.
