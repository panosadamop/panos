# Product Vision

## Product

**Panos** is a personal, local-first AI workstation assistant that can understand natural written or spoken instructions, reason about software and business requirements, control approved computer capabilities, and autonomously execute long-running knowledge-work and software-development workflows.

## Experience

The user interacts with one assistant/personality called **Panos**. Specialist agents are internal implementation details.

Example:

> Panos, create a contract-management application using Spring Boot, Vaadin and PostgreSQL.

Panos interviews the user, produces requirements, waits for approval, creates architecture/backlog/estimates, generates project-specific Claude skills, scaffolds the repository, implements and tests the application, and opens it in the preferred IDE.

## Platforms

- Windows
- macOS
- Linux
- Web control dashboard
- iOS/Android companion in a later phase

## Interaction

- Always-on local wake-word detection for `Panos`
- Configurable global hotkey
- CLI
- Desktop UI
- Greek, English and mixed Greek/English technical speech
- Written + spoken responses

## Principles

- Local-first and offline-capable
- Privacy by policy, including local-only projects/folders
- Human approval for consequential actions
- Deterministic tools around probabilistic AI
- Full auditability
- Requirement-to-code/test traceability
- Cross-platform adapters
- Provider-neutral AI architecture
