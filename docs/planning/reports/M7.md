## Known limitations

1. **The wake word "Panos" is not trained yet.** Push-to-talk is the primary trigger; `hey_jarvis` is opt-in for development.
2. **Mixed Greek/English STT is unverified with real speech** (AC-US003-01/02 open). Greek STT with `small` on CPU is fine for commands but weak for dictation (S-1: CER ~9 %).
3. **No local vision model is pulled**, so screen analysis has not been run live. On CPU, a 4B vision model will be slow.
4. **The `screen.captured` audit record stores the window title,** which can be sensitive.
5. **Model downloads have no checksum verification** (ADR-021); they use pinned release tags over HTTPS.
6. **The installer has been built but not run;** it is unsigned. Only Windows/NSIS is built; macOS/Linux bundles are not.
7. **macOS/Linux screen capture is degraded** (full primary screen, no macOS permission flow, no Wayland).
8. **No Playwright end-to-end UI tests;** Vitest + RTL + axe cover the views against a fake API. The UI has no inline diff viewer for approvals and cannot change a project's privacy mode (use the CLI).
9. **CI risk:** the voice wheels (onnxruntime, ctranslate2, Piper) on Python 3.14 across all three OSes are unproven until a remote exists.
10. **The 30-minute approval TTL** may be short when approvals arrive as desktop or voice notifications while the user is away (carried over from M5).
11. **The sidecar is 315 MB:** voice dependencies dominate. A no-voice build is possible (`build_sidecar.py` without `--voice`).
