## Defects found and fixed during M8 verification

1. `build_default_registry` dropped the requirements service, so work-item changes were never linked as evidence (AC-US042-02).
2. A work-item `create` ignored the change set's project.
3. A comment's id was reported as the work-item key, which also gave a wrong `/browse/` link.
4. Context assembly re-sorts retrieval by scope. Collection hits passed as `project` would have undone the FR-020 order, so the tier now sets the scope.
5. Real Chromium: a page's own `form.submit()` was blocked correctly, but the failed navigation replaced the page with an error page. Submission is now neutralised inside the page.
6. An unreachable website was reported as "disallowed by robots.txt". It is now a transient failure that keeps the last indexed version.
7. Live research: qwen2.5:3b cited Wikipedia's own footnote `[5]` instead of the source number. Footnote markers are now stripped (answer: "According to [1] … 9.6 GW", cited `[1]`).
8. Frozen build: Playwright looked for Chromium inside the bundle. It now uses the per-user browser cache.

## Known limitations

1. Connector code is verified against a faithful fake cloud only. Real API quirks (paging, throttling, consent screens) may still surface in the live checks.
2. Web search does not work out of the box (R-15). Research with given URLs does.
3. Knowledge collections are lexical only (no embeddings yet). Website collections index only the listed pages (no crawling).
4. Google OAuth apps in "Testing" mode issue 7-day refresh tokens.
5. Browser tools are refused in LOCAL_ONLY projects by design. Chat research there runs outside the project.
6. There are no mail or calendar CLI commands; these are available through chat intents and tools.
7. Microsoft 365 mail/calendar, Outlook COM and Thunderbird are deferred, as is browser form submission.
8. The frozen sidecar grew to 445 MB, and Chromium is not bundled.
9. `tests/e2e/test_node_daemon.py` timed out twice (60 s node start) while heavy work ran alongside it; it passes 7/7 on its own.
