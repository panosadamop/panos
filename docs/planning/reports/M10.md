## Corrections made during the milestone

1. Calibration first proposed "base hours-per-point × median ratio". That is wrong when older baselines used another value, so it now uses the median of each story's actual hours ÷ points.
2. Partial work would have biased the factor low. Only stories marked finished count.
3. Playwright's HTTP client ignores the browser's certificate pin, so the manifest check runs inside the page.
4. BR-023 (long-running tasks), implemented in M5, had no tagged test. The job tests now carry the tag, so it appears from the next full run.

## Known limitations

1. Verified with an emulated phone (Chromium mobile emulation), not with real iOS Safari or Android Chrome.
2. There are no system notifications on the phone, only a badge while the app is open (no internet push by design).
3. The phone works only on the LAN (a VPN would be needed away from home).
4. Hours can't be logged from the phone or dashboard yet (CLI and desktop only). Calibration is per technology/overall, not per role.
5. Analytics show totals, meters and tables. The daily series exists in the API but is not charted.
6. Earlier open items still stand: the M9 two-PC check; the M8 live accounts and search provider (R-15); ADR-026…029 decisions.
