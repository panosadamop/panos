## Deviations from plan (documented)

1. **Migrations live in `panos_core/persistence/migrations/`**, not root `/migrations`, so the node can self-upgrade, including in a frozen build (ADR-004 amended).
2. **CI Python matrix is 3.12 + 3.14** (minimum + current) instead of 3.12 + 3.13. 3.14 is the current stable release.
3. **`platform/posix/`** holds shared macOS/Linux code. Separate `macos/` and `linux/` packages will be added where the implementations differ (M3).
4. **TypeScript/pnpm workspace not created yet.** There are no TS packages until M7, so an empty pnpm workspace would only add noise.

## Issues found and fixed during M1

- `win32security.PySID` exists only in the type stubs, so evaluating the annotation crashed `panos serve` on start. Fixed with lazy annotations; the e2e test now covers the start path.
- **Windows shutdown:** current uvicorn re-raises the captured signal after a graceful shutdown. On Windows a re-raised `SIGBREAK` kills the process before `finally` runs, leaving a stale runtime file. Fixed with an idempotent cleanup hook in the app lifespan, plus `finally` as a backstop. Covered by e2e.
- **Insert ordering:** with no ORM relationships, SQLAlchemy did not order inserts by foreign key. Fixed by flushing on `add`.
- On Windows a venv's `python.exe` is a launcher process, so the node PID ≠ the spawned PID. The e2e tests were adjusted. Runtime-file ownership checks use the node's own PID.

## Known limitations

- CI has not run on macOS/Linux, because there is no remote yet. POSIX code paths (`platform/posix`, `0600` check) are unit-tested only on POSIX runners, and one test was skipped locally.
- The CLI does not auto-start the daemon yet (ADR-002 option). `panos serve` runs in the foreground. Auto-start and a background/tray lifecycle come with M3/M7.
- WebSocket token authentication (first-message auth) arrives with `/ws/events` in M4. M1 enforces only Host and Origin on WebSocket handshakes.
- Redaction uses the initial pattern set. Entropy-based detection and the corpus suite are M2-09.
- The audit hash chain (ADR-020) is M2-08. The `seq` column is already in place for it.
- `server.py` coverage comes only from e2e subprocesses, which are not measured by coverage, plus two in-process tests.
- Starlette 1.x warns that its TestClient's use of httpx is deprecated. The warning is filtered with a note, pending FastAPI's TestClient migration.
