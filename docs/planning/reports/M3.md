## Bugs and issues found during M3

1. **Race in app discovery:** the startup background refresh and an explicit refresh both inserted the same key (UNIQUE violation). Fixed with a refresh lock; discovery now also runs off the event loop.
2. **Greek search did not work:** FTS5 `remove_diacritics` folds only Latin accents. Fixed with Panos-side normalization (index schema v3).
3. **False infrastructure detection on this very repo** (Azure/K8s/Terraform from `tests/fixtures`). Fixture and sample directories are now excluded from infrastructure and monorepo signals.
4. **Normalized snippets were unreadable.** The original text is now stored and shown.
5. **Edge's uninstall entry points into a version folder** that changes on update. Browsers now prefer the App Paths launcher.
6. **Stale `monorepo?` question for declared workspaces** (e.g. this uv workspace). Now suppressed when the root declares a workspace.

## Deviations from plan

1. **No tree-sitter yet.** Symbol outlines use Python `ast` plus regexes (names only). A full multi-language parser is deferred to when the coding agent needs it (M5), avoiding a large native dependency now.
2. **Knowledge index uses `PRAGMA user_version`, not Alembic.** It is a derived, rebuildable cache (ADR-017 note).
3. **The catalog is the allowlist** for "approved applications". There is no user-editable app list yet.
4. API routes were restructured into a `routers/` package (no contract change; OpenAPI regenerated).

## Known limitations

- **Coverage under-reports async API handlers:** lines after the first `await` in endpoints running in TestClient's portal thread are not traced, although tests exercise them and assert on responses. The real coverage of `routers/` is higher than reported.
- Only the root `.gitignore` is honored by the walker. Nested ignore files are not.
- `.gitignore`d but sensitive files outside ignore rules (e.g. a committed `.env`) would be indexed. Indexing follows project privacy (LOCAL_ONLY by default); content-level secret filtering of the index arrives with M4 prompt building.
- macOS/Linux active-window and focus: unsupported until M7. Wayland launch/open via `xdg-open` only.
- Windows `SetForegroundWindow` may be refused by the OS's foreground-lock rules; `app.focus` reports `focused: false` rather than forcing it.
- Analysis runs in-process on demand. There is no file watcher yet; re-run `analyze`/`index` after big changes.
- Still no CI remote: macOS/Linux paths are untested locally.
