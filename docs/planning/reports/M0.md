## S-1 key outcomes (impact on plan)

- **Hardware is CPU-only.** The Radeon 680M is not used by Ollama by default.
- **Local LLM speeds:** 3B 11–13 tok/s, 7B coder 5–7 tok/s, 14B 2.8 tok/s. Local-only coding therefore runs as background jobs (ADR-009). R-5 was raised to High likelihood.
- **STT:** faster-whisper `small` takes ~2.7 s per command (Greek CER 9 %), making it the default. `medium`/`turbo` take 8–11 s, so they are an opt-in accurate mode. Auto language detection is unreliable for mixed speech, so Greek is the default language with a vocabulary prompt.
- **Wake word:** openWakeWord is cheap (5 ms per frame), but a custom "Panos" model needs WSL2 training. A new backlog item **M7-07a** covers this. The hotkey is the primary MVP trigger.
- **TTS:** Piper `el_GR-joy-medium` + `en_US-lessac-medium` with a language-run splitter. No Greek Windows voice is installed on this machine (R-4 corrected).
